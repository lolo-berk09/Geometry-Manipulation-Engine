# Geometry-Manipulation-Engine
An interactive geometry visualization and exploration tool designed to help students understand the mathematics behind geometric shapes, measurements, and relationships.
---
## Overview
The engine is an interactive, browser-based application that allows its users to build, manipulate, and explore geometric objects on a coordinate plane. 

The project was developed with the goal of making geometry easier to understand and more accessible. The math explorer panel within the engine connects the visual shapes with the calculations and formulas behind them. The Geometry Engine is designed to make mathematical relationships more interactive, visual, and comprehensive.

---
## Features
Creation
- create and select points on a coordinate plane
- create lines, circles, triangles, rectangles, and polygons
- use adaptive grid snapping for more precise placement
- zoom in and zoom out controls inside the coordinate window

Mathematical Measurements
- calculate distance between two points
- determine line slopes
- identify intersections between lines
- calculate angles and interior angle sums
- determine the area and perimeter of polygons
- calculate circle area and circumference

Visualization
- display geometric intersection and angle measurements
- visualize interior angles of the shapes

Math Explorer
Depending on the selected object,
users can explore:
- mathematical formulas and their applications
- step-by-step calculations
- coordinate substitutions
- geometric properties of shapes

## How to Use
1. Getting started
   Open the Geometry Engine in your browser to access the interactive coordinate plane. The canvas displays a grid where you can create, select, and explore geometric objects.
   For a guided instruction to the navigate the engine, click the User Guide button on the top right corner. The tutorial walks you through the main features and tools, and can be skipped or revisited at any time.
2. Creating Geometric Objects
   Use the toolbar to the left go choose the type of object you want to create.

   The engine supports:
   - Points: place individual points on the coordinate plane
   - Line Segments: create lines by connecting 2 points
   - Triangles: construct triangles by connecting 3 points
   - Rectangles: construct rectangles by connecting 4 points
   - Polygons: construct polygons by connecting 3 or more points and selecting the starting point to enclose the shape
   - Circles: create circles using a center point and a radius point

3. Selecting and Exploring Objects
   Use the Select tool to interact with objects on the coordinate plane.

   When the object is selected, the Math Explorer panel displays information about it, including its coordinates and relevant mathematical properties.

4. Mathematical Visualization
The Engine displays interior angles and measurements of all shapes and geometric objects.

Use the Hide/Show Intersections & Angles button in the top toolbar to toggle these visualizations on or off.

5. Math Explorer & Equation Library
   The Math Explorer provides mathematical information about a selected object

   You can also open the Equation Library to explore useful geometry formulas and explanations. Equations are organized into categories, and each entry can be expanded or collapsed to reveal more information. Multiple explanations can be open simultaneously.
